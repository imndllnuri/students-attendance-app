What it does

Built for one person running a real classroom

Not a platform to onboard onto. A desktop app you install, point at a folder, and use for the term.

Tap to record

A student taps their card and the reader shows their name back. The app marks them Present or Late against the session's own start time and threshold.

Your files, not our database

A vault is a plain folder of JSON and XLSX. Back it up, copy it to a USB stick, open the spreadsheet in Excel. Nothing is locked in a format only TapIn reads.

Statistics that answer questions

Per-class breakdown and trend, a heatmap across sessions, and a comparison across every class you teach — plus who is below your attendance policy.

Export anything

The roster, the full attendance grid, one student's history, a PDF class report, or a signed-looking certificate of attendance for a single student.

No reader? Still works

Manual entry, "mark all present", and bulk-marking absentees all work with no hardware at all. The reader makes it faster; it is not a requirement.

English and Turkish

The whole interface, including dates and weekday names, switches between English and Turkish from Settings.

Hardware

How the reader fits in

TapIn works with an ESP32-based RFID reader over USB, or over the reader's own WiFi hotspot. It is optional — manual entry and bulk marking work with no hardware at all.

ESP32 + RC522Reads the card, sends the serial number
USB cable or WiFiCable by default; the board can host its own hotspot
TapInResolves the card to a student, records the session
Your vault folderPlain files on your own disk

The board only ever sends a number

The reader has no roster and no idea who anyone is. It sends a card's serial number; the app looks up who that is and sends the name back for the reader's screen. Names never live on the device, so a reader that is lost or taken apart gives up nothing about your students.

Installing

First run, step by step

Windows 10/11

  1. Run the setup fileTapIn-x.y.z-setup.exe
  2. Click through the wizardInstalls for your user only — no administrator password needed
  3. Launch from the Start menuUninstall from Settings → Apps like any other program

Windows SmartScreen may warn on first run because the installer is not code-signed. Choose More info → Run anyway.

Debian / Ubuntu

  1. Install the packageDouble-click it, or use the command below
  2. Find TapIn in your applications menuOr run tapin in a terminal
  3. Remove it any timesudo apt remove tapin
sudo apt install ./tapin_*_amd64.deb

Other Linux & macOS

  1. Unzip the archiveIt carries its own Python and Qt
  2. Run the launcher./TapIn/TapIn, or open TapIn.app on macOS
  3. Keep the folder togetherThe app reads files next to it, so move the whole folder, not just the binary

These are archives, not installers — there is no Start-menu entry or uninstaller. macOS is unsigned, so allow it under System Settings → Privacy & Security.

Then, on first launch

  1. Choose a vault folderAn empty folder anywhere you like. Everything TapIn stores goes here — put it in your usual backed-up location.
  2. Add a classCode, name, weekly schedule and attendance policy. Import the roster from CSV or Excel, or type it in.
  3. Bind cardsAdd a student and scan their card in one step, or bind cards to an existing roster from the class screen.
  4. Take attendancePress Start Attendance and let students tap. Submit when the session ends.

Privacy

Where the data goes

By design

Nothing leaves your machine

TapIn has no telemetry, no analytics and no accounts. Out of the box the only network connection it opens is to your own card reader, on your own local network, and only if you have configured the WiFi reader. Physical access to the vault folder is the entire access model — protect it the way you would protect a paper gradebook.

One exception

The update check is off until you switch it on

Settings has a switch called Check for New Versions, and it ships off. Turn it on and TapIn asks github.com once at startup for the version number of the newest release, then tells you in Notifications if yours is older. The request carries no student data, no vault path and no identifier — it reads the same public page anyone can open in a browser. Nothing is downloaded or installed. Leave the switch off and TapIn never contacts github.com at all.

Worth knowing

Uninstalling never deletes your records

Your vault is a folder you chose, so removing TapIn leaves it exactly where it is. That is deliberate: quietly deleting a term of attendance records because someone uninstalled an app would be indefensible. Delete the folder yourself when you actually want it gone.

FAQ

Common questions

Do I need the RFID reader to use TapIn?

No. Manual Attendance Entry, "Mark All Present" and bulk absence marking all work with no hardware. The reader makes a large class faster; it is not required for any feature.

Can two people use the same vault?

Not at the same time. A vault is locked while TapIn has it open, so a second instance is refused rather than allowed to corrupt it. Sharing a vault on a network drive between two people at once is not supported.

What happens if a student loses their card?

Open the class, double-click the student, and choose Remove Card. The card stops being recognised in every class that student is enrolled in — not just the one you are looking at — and can then be issued to someone else.

One student is in three of my classes. Do I register their card three times?

No. A card belongs to a person, so registering it once writes it to every roster row that shares that student number. The reverse is enforced too: a card already held by a different student is refused rather than silently reassigned.

Can I move my vault to another computer?

Yes — copy the folder. There is no license key, no activation and no machine binding. Point TapIn at the copied folder on the new machine and everything is there.

Will TapIn tell me when a new version is out?

Only if you ask it to. Settings → Updates has a Check for New Versions switch that is off by default. With it on, TapIn checks this project's public releases page once at startup and puts a line in Notifications when a newer version exists. It never downloads or installs anything by itself — you come back here and run the installer when you want to. With it off, no check is made.

Does the WiFi reader need internet?

No, and it does not connect to your institution's network either. The board hosts its own small hotspot that your laptop joins directly. That does mean the laptop has no internet while scanning.

Is my Excel file safe to open while TapIn is running?

Opening it is fine. Keeping it open while TapIn tries to save is not — on Windows, Excel locks the file. TapIn queues the submission and retries rather than losing it, but closing the spreadsheet first avoids the round trip.

What does it cost?

Nothing. TapIn is free to download and use — no subscription, no account and no licence key.
