# TapIn

Class attendance from RFID cards — or by hand — kept as ordinary files in a
folder you choose. No server, no account.

**Download TapIn:** <https://imndllnuri.github.io/students-attendance-app/>
(Türkçe: <https://imndllnuri.github.io/students-attendance-app/tr/>)

This repository holds TapIn's website and its installers. The application's
source code is kept in a separate, private repository.
